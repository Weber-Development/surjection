# @sweberdev/surjection-react

Small, unstyled accessible building blocks for React: `SkipLink`, `VisuallyHidden`, `AnnouncerProvider` with `useAnnounce`, and `useReducedMotion`. Part of [Surjection](https://packages.sweber.dev/surjection).

```tsx
import { SkipLink, AnnouncerProvider, useAnnounce } from "@sweberdev/surjection-react";
```

Checks for CI and tests live in [`@sweberdev/surjection`](https://www.npmjs.com/package/@sweberdev/surjection). Docs: [packages.sweber.dev/surjection/docs](https://packages.sweber.dev/surjection/docs).

MIT.
